  • 根据配置启动真正的业务服务；
  • 最后退出 bootstrap 过程。

9. 总结

从源码角度来看，skynet 的启动过程可以概括为一个清晰的链路：

  1. 入口函数读取配置文件并准备环境。
  2. 初始化各个底层模块，如消息队列、句柄、网络、定时器和服务模块。
  3. 创建日志服务实例。
  4. 启动 bootstrap 服务。
  5. bootstrap 进一步创建 snlua 服务，并加载 Lua 脚本。
  6. Lua 层的 bootstrap.lua 负责启动一系列基础服务和业务服务。

因此，skynet 的启动并不是单纯“启动一个进程”，而是一个“从 C 层初始化框架，再把控制权交给 Lua 层”的完整流程。只有把这条链路理清楚，后续在分析消息派发、服务调度、定时器和网络模块时，才会更容易把握整体架构。
